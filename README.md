# air-quality-prediction

This project predicts PM2.5 concentrations using historical weather observations and machine learning models.

## Dataset

- Beijing Multi-Site Air Quality Dataset (UCI)

## Models

- Linear Regression
- Random Forest
- XGBoost

## API

- Open-Meteo

## Technologies

- Python
- Pandas
- Scikit-Learn
- Matplotlib
